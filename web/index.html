CF Evolution

A Java-based open-source editor for Geoff Crammond’s Formula One Grand Prix / World Circuit racing classic.

Download latest View source
Latest version · What’s new · Requires Java 8 or later

●Whole game folder

Open your game folder to edit the game program, all 16 circuits and the other game files, each in its own tab. A copy of the originals is kept the first time.

●Track editing

Edit game tracks while viewing a live map.

●Best line tools

Edit the AI racing line manually, or generate a new one by fastest-lap simulation.

●Random tracks

Generate complete new circuit layouts with a best line in one click.

●Executable editor

Edit drivers, teams, points, setups, game settings and the colours of every car, helmet and pit crew in GP.EXE.

●Game files and carsets

Edit game options, saved setups, name files, pictures and sound effects. Move your changes to another game folder as a dataset, or import and export F1ED and ArgEditor carsets.

●Cross-platform

Supported on Windows, macOS and Linux.

●Under development

CF Evolution is still in active development.

Built to edit a classic

CF Evolution is the successor to the Chequered Flag project, continuing from its 0.1.1 codebase with substantial bug fixes, new features and active development.

Formula One Grand Prix (World Circuit in North America) was released by MicroProse on PC in 1992 and set the standard for racing simulations at the time. Despite the age of the game, there is still a limited community who play the game and continue development.
